# brew-beats ☕

A browser-based beat maker built for coffee shops.  
One HTML file. No frameworks. No dependencies. Just vibes.

## What is this?

Coffee tasting notes meet beat making.  
Pick a MOOD, hit **BREW IT**, and let it play.

## Tech

- Web Audio API only
- Single `.html` file
- No build tools. No npm. Just open and play.
